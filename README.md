# Public CA Transparency Repository

This repository contains **public certificates and metadata** from our certificate authority. **No private keys** are included.

More techncical details about this repo can be found in [README-howto.md](README-howto.md).

## Structure
```
/
├── CA/ # Root CA certificate
├── intermediate-stg/ # Staging intermediate (NOT signed by root)
└── intermediate-prod/ # Production intermediate (signed by root)
```
